## General updates

- Sort the vault by Recent activity: the latest of when you used, added or edited each item.
- A revealed password shows the position of each character, for sites that ask for, say, the 3rd and 7th.
- Items you archived in 1Password stay archived when you import them.
- Bramble is now available in Bengali.

## Desktop (macOS, Linux, Windows)

- On macOS, Bramble is now in AutoFill & Passwords: choose Bramble under AutoFill from and Set Up Codes In in System Settings > General > AutoFill & Passwords to fill passwords, passkeys and verification codes in Safari and other Mac apps, and set up a code from a site's setup link.
- The app installs an update only once it is in a public log (Sigsum), so a version made for you alone would be seen; the Linux .deb and AppImage can be rebuilt byte for byte.
- Linking reaches Orion, and Zen or Floorp on a Mac without Firefox; choosing Connect rewrites the files browsers use to find the app.
- Open website and other web links open in your browser again.
- Exporting and opening .bramble files works.
- Shift-click selects a range of items in selection mode.

## Browser extensions

- Logins that match the page have a Fill button in Bramble's window, and the fill shortcut fills the code on a two-factor field.
- Linking to the desktop app gives up after 15 seconds with a message if the app never answers, instead of waiting forever.
- Zen and Orion show under their own names when you link or pair them.
- Shift-click selects a range of items in selection mode.
- In Firefox, security keys work while Bramble serves passkeys, and sites such as Google offer a passkey on Linux.
- The pop-out no longer changes the size and position of new Firefox windows.
- In Firefox, opening website from the pop-out opens the site in your browser window, not inside the pop-out.

## Mobile

- When autofill has no login for a sign-up form, choose New login from the autofill list to make one, with a generated password, and fill it in one step.
