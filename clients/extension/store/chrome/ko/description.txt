Bramble은 무료 오픈소스 비밀번호 관리자로, 비밀을 사용자의 기기에만 보관합니다. 계정도, 볼트를 보관하는 서버도, 해킹당해 모든 것을 유출할 회사도 없습니다. 볼트도 비밀번호도 사용자가 직접 갖고, 그게 전부입니다.

Chrome, Edge, Brave, Arc 및 기타 Chromium 브라우저에서 작동합니다. 설치하면 약 1분 안에 사용할 수 있습니다. Bramble은 macOS, Linux, iOS, Android 앱도 제공하며, 볼트가 이 모든 기기 간에 동기화됩니다.

하는 일

비밀번호는 기기에서 암호화되어 브라우저의 개인 저장소에 보관됩니다. 한 번 설정하면 로그인 자동 완성, 새 로그인 저장, 비밀번호 생성이 바로 가능합니다.

기기가 두 대 이상인가요? 기기를 페어링하면 Bramble이 볼트를 기기 간에 직접, 종단 간 암호화로 동기화합니다. 기기를 연결해 주는 릴레이는 암호문만 볼 수 있고 아무것도 저장하지 않으므로, 비밀 정보는 누구의 서버에도 남지 않습니다.

기능

- 항상 로컬 우선. 암호화된 볼트는 기기, 즉 브라우저의 개인 저장소에만 있습니다. 계정도, 서버 복사본도 없습니다.
- P2P 동기화. 기기가 종단 간 암호화된 연결을 통해 항목 단위로 병합되며 동기화 상태를 유지합니다. 기기를 연결하는 릴레이는 암호문만 볼 수 있고 아무것도 저장하지 않습니다.
- 견고한 암호화. 키에는 Argon2id, 데이터에는 AES-256-GCM, 항목마다 자체 키를 갖도록 봉투 암호화를 사용합니다. 사용 후 비밀 정보는 메모리에서 삭제됩니다.
- 모든 항목 암호화. 사이트 이름, 사용자 이름, 메모까지 전부 암호화합니다.
- 도메인 인식 자동 완성. www.example.com, ca.accounts.example.com, example.com이 모두 하나의 로그인과 일치합니다. 페이지 내 드롭다운은 iframe과 shadow DOM 안의 폼에도 작동합니다.
- 패스키. Bramble은 사용자 자신의 패스키 인증자입니다. 패스키를 만들고 로그인할 수 있으며 볼트에 저장되어 다른 항목처럼 동기화됩니다.
- 로그인 이상. 로그인, 결제 카드, 보안 메모, SSH 키를 각각 전용 필드로 관리합니다.
- 이메일 별칭. Addy.io, SimpleLogin, Fastmail 또는 직접 보유한 도메인을 통해 사이트마다 고유한 전달 주소를 만들 수 있으며, 가입 양식에서 바로 제공됩니다.
- 탭하여 잠금 해제. YubiKey, Touch ID, Windows Hello를 등록하고 WebAuthn PRF로 탭 한 번에 잠금 해제할 수 있습니다. 마스터 비밀번호와 함께 사용하거나 유일한 인증 수단으로 사용할 수 있습니다.
- 복구 코드. 모든 볼트는 설정 시 안전한 복구 코드를 받습니다. 마스터 비밀번호 없이 볼트를 잠금 해제할 수 있는 인쇄 가능한 백업입니다.
- TOTP / 2FA 코드. otpauth:// URI 또는 비밀 키를 붙여넣으면 Bramble이 코드를 생성합니다.
- 암호화된 백업. 볼트를 언제든지 암호화된 파일로 내보내거나 Dropbox, S3 호환 버킷 또는 WebDAV로 암호화된 백업을 예약할 수 있습니다. 제공업체는 오직 암호문만 볼 수 있습니다.
- 종속 없음. 원할 때마다 표준 KeePass(.kdbx) 파일로 내보낼 수 있습니다.
- 여러 볼트. 별도의 볼트를 나란히 두고 각각 고유한 마스터 비밀번호로 보호할 수 있습니다.
- 내장 비밀번호 생성기.
- 선택적 유출 확인. k-익명성을 이용한 Have I Been Pwned 조회로 비밀번호에 관한 어떤 정보도 기기를 떠나지 않습니다. 기본적으로 꺼져 있습니다.
- 유휴 상태 15분 후 자동 잠금(설정 가능).
- 손쉬운 전환. 다른 비밀번호 관리자나 KeePass 파일에서 가져올 수 있습니다.

로컬 우선인 이유

클라우드 관리자는 모든 사용자의 볼트를 서버에 보관하므로 하나의 거대한 공격 대상이 됩니다. 한 번 뚫리면 볼트 하나가 아니라 수백만 개가 한꺼번에 유출되며, 공개가 몇 달 뒤에야 이뤄지기도 합니다.

Bramble은 이를 뒤집습니다.

- 공격할 서버 없음. 볼트는 절대 사용자의 통제를 벗어나지 않습니다.
- 계정도, 구독도, 광고도, 원격 측정도 없습니다. 가입할 것도 없습니다.
- 데이터도, 기기도 사용자의 것입니다. 자신의 기기 간에 동기화하거나, 한 기기에 보관하거나, 선택한 저장소에 암호화하여 백업할 수 있습니다. 읽을 수 있는 어떤 것도 다른 사람의 서버에 저장되지 않습니다.
- 믿을 것은 코드뿐. Bramble은 GPL에 따라 오픈소스이며 코드는 GitHub에 공개되어 있습니다.

암호화 작동 방식

Bramble은 LUKS 방식의 키 슬롯과 봉투 암호화를 사용합니다. 하나의 무작위 볼트 키가 데이터를 보호합니다. 각 잠금 해제 방법(마스터 비밀번호, 보안 키, 복구 코드)은 동일한 볼트 키의 복사본을 풀 수 있는 자체 키 암호화 키를 도출하므로, 잠금 해제 방법을 추가하거나 취소해도 항목 하나도 다시 암호화하지 않습니다. 그런 다음 볼트 키가 모든 항목에 대해 새로운 항목별 키를 풀어줍니다. 모든 것은 AES-256-GCM입니다.

KeePass에서 넘어오시나요?

KeePass 사용자라면 익숙할 것입니다. 암호화된 볼트, 사용자의 통제권, 클라우드 중개자 없음. Bramble은 KDBX4 파일(키 파일 포함)을 가져오고, 원할 때마다 .kdbx로 내보낼 수 있습니다. 차이점: 자동 완성이 내장되어 도메인 일치와 페이지 내 드롭다운이 제공되므로 플러그인 브리지가 필요 없습니다. 기기 간 동기화도 내장되어 있고, 여러 플러그인이 아닌 Argon2id와 AES-256-GCM을 사용하는 하나의 최신 빌드로 제공됩니다. 깔끔한 UI, 다크 모드 포함.
