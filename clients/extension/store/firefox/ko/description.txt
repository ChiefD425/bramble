Bramble은 무료 오픈소스 비밀번호 관리자로, 비밀 정보를 사용자 본인의 기기에 보관합니다. 계정도 없고, 볼트를 보관하는 서버도 없고, 침해되어 모든 것을 유출할 회사도 없습니다. 볼트도, 비밀번호도 사용자가 보관합니다. 그게 전부입니다.

Firefox, LibreWolf, Waterfox, Zen 및 기타 Firefox 기반 브라우저에서 작동합니다. 설치하면 약 1분 안에 바로 사용할 수 있습니다. Bramble은 macOS, Linux, iOS 및 Android용 앱도 제공하며, 볼트는 모든 기기 간에 동기화됩니다.

기능 개요

비밀번호는 기기에서 암호화되어 브라우저의 자체 확장 프로그램 저장소에 보관됩니다. 한 번 설정하면 바로 로그인 자동 완성, 새 로그인 저장, 비밀번호 생성이 가능합니다.

기기가 여러 대입니까? 기기들을 페어링하면 Bramble이 볼트를 기기 간에 종단 간 암호화로 직접 동기화합니다. 기기를 연결해 주는 릴레이는 암호문만 볼 수 있고 아무것도 저장하지 않으므로, 비밀 정보는 누구의 서버에도 저장되지 않습니다.

주요 기능

- 항상 로컬 우선. 암호화된 볼트는 사용자 기기의 브라우저 저장소에 그대로 있습니다. 계정도, 서버 사본도 없습니다.
- 피어 투 피어 동기화. 종단 간 암호화된 연결을 통해 기기가 항목별로 병합되며 동기화됩니다. 기기를 연결해 주는 릴레이는 암호문만 볼 수 있고 아무것도 저장하지 않습니다.
- 강력한 암호화. 키에는 Argon2id, 데이터에는 AES-256-GCM, 항목마다 자체 키를 사용하는 봉투 암호화를 적용합니다. 사용 후 비밀 정보는 메모리에서 삭제됩니다.
- 모든 항목 암호화. 사이트 이름, 사용자 이름, 메모까지 전부 암호화됩니다.
- 도메인 인식 자동 완성. www.example.com, ca.accounts.example.com, example.com이 하나의 로그인 항목으로 매칭됩니다. 페이지 내 드롭다운은 iframe과 shadow DOM 안의 양식에도 접근합니다.
- 패스키. Bramble은 사용자 자신의 패스키 인증자입니다. 패스키를 만들고 로그인할 수 있으며, 볼트에 저장되고 다른 항목처럼 동기화됩니다.
- 로그인 이상. 로그인, 결제 카드, 보안 메모, SSH 키를 각각 전용 필드와 함께 관리합니다.
- 이메일 별칭. 가입 양식에서 바로 Addy.io, SimpleLogin, Fastmail 또는 사용자가 소유한 도메인을 통해 사이트별 고유 전달 주소를 만들 수 있습니다.
- 탭으로 잠금 해제. 마스터 비밀번호와 함께 Touch ID 또는 Windows Hello를 사용하거나, 유일한 로그인 수단으로 설정할 수 있습니다.
- 복구 코드. 모든 볼트는 설정 시 안전한 복구 코드를 받습니다. 마스터 비밀번호 없이도 볼트를 열 수 있는 인쇄 가능한 백업입니다.
- TOTP / 2FA 코드. otpauth:// URI 또는 시크릿을 붙여 넣으면 Bramble이 코드를 생성합니다.
- 암호화된 백업. 언제든지 볼트를 암호화된 파일로 내보내거나, Dropbox, S3 호환 버킷 또는 WebDAV로 암호화 백업을 예약할 수 있습니다. 제공업체는 암호문만 볼 수 있습니다.
- 종속 없음. 원할 때 언제든지 표준 KeePass(.kdbx) 파일로 내보낼 수 있습니다.
- 여러 볼트. 각각 고유한 마스터 비밀번호로 보호되는 별도의 볼트를 나란히 유지할 수 있습니다.
- 내장 비밀번호 생성기.
- 선택적 유출 확인. k-익명성을 사용한 Have I Been Pwned 조회로, 비밀번호에 관한 어떤 정보도 기기를 떠나지 않습니다. 기본적으로 꺼져 있습니다.
- 유휴 상태 15분 후 자동 잠금(설정 가능).
- 1Password, Bitwarden, Proton Pass, LastPass, Dashlane, Enpass, AliasVault, RoboForm, KeePass, Firefox, Apple Passwords, Google Password Manager에서 가져오기.

로컬 우선인 이유

클라우드 관리자는 모든 사용자의 볼트를 자사 서버에 보관하므로 하나의 거대한 표적이 됩니다. 한 번 침해되면 하나의 볼트가 아니라 수백만 개가 한꺼번에 유출되며, 많은 경우 몇 달 뒤에야 공개됩니다.

Bramble은 이 구조를 뒤집습니다.

- 침해될 서버가 없습니다. 볼트는 사용자의 통제를 벗어나지 않습니다.
- 계정도, 구독도, 광고도, 원격 측정도 없습니다. 가입할 것도 없습니다.
- 데이터와 기기는 사용자의 것입니다. 자신의 기기 간에 동기화하거나, 한 대에만 보관하거나, 선택한 저장소에 암호화하여 백업할 수 있습니다. 읽을 수 있는 어떤 것도 타사 서버에 보관되지 않습니다.
- 믿을 것은 코드뿐입니다. Bramble은 GPL 하의 오픈소스이며, 코드는 GitHub에 공개되어 있습니다.

암호화 작동 방식

Bramble은 LUKS 방식의 키 슬롯과 봉투 암호화를 사용합니다. 하나의 무작위 Vault Key가 데이터를 보호합니다. 각 잠금 해제 수단(마스터 비밀번호, Touch ID 또는 Windows Hello, 복구 코드)은 동일한 Vault Key 사본을 풀어내는 고유한 Key-Encryption Key를 파생합니다. 따라서 잠금 해제 수단을 추가하거나 철회해도 항목 하나도 다시 암호화되지 않습니다. 그런 다음 Vault Key가 항목마다 새로운 항목별 키를 풀어냅니다. 모든 항목은 AES-256-GCM으로 암호화됩니다.

KeePass에서 넘어오시나요?

익숙하게 느껴지실 것입니다. 암호화된 볼트, 사용자의 통제권, 클라우드 중간자 없음. Bramble은 KDBX4 파일(키 파일 포함)을 가져오고, 원할 때 언제든지 .kdbx로 다시 내보낼 수 있습니다. 차이점은 다음과 같습니다. 자동 완성이 내장되어 있고 도메인 매칭과 페이지 내 드롭다운을 제공하므로 플러그인 브리지가 필요 없습니다. 기기 간 동기화도 내장되어 있습니다. 그리고 플러그인을 늘어놓는 대신 Argon2id와 AES-256-GCM을 사용하는 하나의 현대적인 빌드로 제공됩니다. 깔끔한 UI, 다크 모드 포함.
