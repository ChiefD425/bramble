Bramble은 로컬 우선 비밀번호 관리자입니다. 비밀번호는 기기의 암호화된 볼트에 보관되며 사용 계정이 필요하지 않습니다. 동기화나 백업을 위해 기기를 떠나는 모든 데이터는 먼저 종단 간 암호화되므로 어떤 서버도 읽을 수 없습니다.

모든 암호화 작업은 Rust 코어에서 실행됩니다. Argon2id가 키를 유도하고, AES-256-GCM이 데이터를 암호화하며, 엔벨로프 암호화(envelope encryption)는 각 항목에 고유 키를 부여합니다. 사이트 이름, 사용자 이름, 메모는 모두 암호화되고, 비밀 정보는 사용 후 메모리에서 지워집니다.

주요 기능
- 비밀번호와 일회용 코드를 키보드에서 바로 앱과 Safari에 자동 완성합니다.
- 패스키: 패스키를 지원하는 사이트와 앱에서 Bramble을 본인의 인증자로 사용해 패스키를 만들고 로그인합니다.
- Face ID, Touch ID, 마스터 비밀번호 또는 복구 코드로 잠금 해제합니다.
- 로그인, 결제 카드, 보안 메모, SSH 키를 각각 전용 필드에 저장합니다.
- 강력한 비밀번호 생성기가 내장되어 있습니다.
- TOTP / 2FA: otpauth URI 또는 시크릿을 추가하면 Bramble이 6자리 코드를 생성합니다.
- KeePass(KDBX4)에서 키 파일을 포함해 가져올 수 있습니다.
- 복구 코드: 인쇄 가능한 높은 엔트로피 백업으로, 마스터 비밀번호 없이도 볼트를 잠금 해제할 수 있습니다.
- 선택적 유출 확인: k-익명성을 사용해 비밀번호 해시의 짧은 접두사만 전송하며 비밀번호는 절대 전송하지 않습니다.
- 비활성 시 자동으로 잠급니다.
- 내 기기 간 동기화는 종단 간 암호화되며, 직접 피어투피어 방식이나 봉인된 데이터만 보관하는 선택적 메일박스 서버를 통해 이루어집니다.
- S3 호환 버킷이나 WebDAV 서버 등 원하는 저장소에 암호화 백업을 선택적으로 만들 수 있습니다.

개인정보 보호
Bramble은 무료 오픈소스(GPLv3)이며 텔레메트리가 없습니다. 계정이 필요 없고 모든 암호화는 기기에서 이루어지며, 내 기기만 볼트를 읽을 수 있습니다. Bramble이 자체적으로 보내는 유일한 요청은 매일 업데이트 확인이며, 설정에서 끌 수 있습니다.
