Bramble은 로컬 우선 방식의 비밀번호 관리자입니다. 비밀번호는 기기의 암호화된 볼트에 저장되며, 이용에 계정이 필요하지 않습니다. 동기화나 백업을 위해 기기를 떠나는 모든 데이터는 먼저 종단 간 암호화되므로 어떤 서버도 읽을 수 없습니다.

모든 암호화 작업은 Rust 코어에서 실행됩니다. Argon2id가 키를 파생하고, AES-256-GCM이 데이터를 암호화하며, 엔벨로프 암호화가 각 항목에 고유한 키를 부여합니다. 사이트 이름, 사용자 이름, 메모가 모두 암호화되며, 비밀 값은 사용 후 메모리에서 지워집니다.

기능

- 앱과 브라우저에 비밀번호와 일회용 코드를 자동 완성합니다.
- 패스키: 패스키를 지원하는 사이트와 앱에서 Bramble을 인증기로 사용해 패스키를 만들고 로그인할 수 있습니다.
- 지문이나 얼굴, 마스터 비밀번호 또는 복구 코드로 잠금을 해제합니다.
- 로그인 정보, 결제 카드, 보안 메모, SSH 키를 각각 전용 필드와 함께 저장합니다.
- 강력한 비밀번호 생성기 내장.
- TOTP / 2FA: otpauth URI 또는 비밀 키를 추가하면 Bramble이 6자리 코드를 생성합니다.
- KeePass(KDBX4)에서 가져오기, 키 파일 포함.
- 복구 코드: 마스터 비밀번호와 별개로 볼트를 잠금 해제할 수 있는 인쇄 가능한 높은 엔트로피 백업.
- k-익명성을 사용한 선택적 유출 여부 확인: 비밀번호 해시의 짧은 접두사만 전송되며 비밀번호 자체는 전송되지 않습니다.
- 비활성 후 자동 잠금.
- 사용자 본인의 기기 간 동기화, 종단 간 암호화: 직접 피어투피어로 하거나, 봉인된 데이터만 보관하는 선택적 메일박스 서버를 통해 동기화합니다.
- S3 호환 버킷이나 WebDAV 서버 등 사용자가 선택한 저장소로의 선택적 암호화 백업.

개인정보 보호

Bramble은 무료 오픈소스(GPLv3)이며 원격 측정이 없습니다. 계정이 필요하지 않으며, 모든 암호화는 사용자의 기기에서 이루어지고, 볼트는 사용자 본인의 기기에서만 읽을 수 있습니다. Bramble이 자체적으로 보내는 유일한 요청은 매일 업데이트 확인이며, 설정에서 끌 수 있습니다.
