macOS에서는 Bramble이 잠금 해제되어 있는 동안 자동 완성이 묻지 않고 입력되며, 빠른 접근 단축키를 변경할 수 있습니다.

- macOS에서는 Bramble이 잠금 해제되어 있는 동안 Touch ID나 마스터 비밀번호를 묻지 않고 자동 완성이 로그인 정보와 2FA 코드를 입력합니다.
- 설정 → 일반 → 빠른 접근 단축키에서 단축키를 변경하거나 끌 수 있습니다.
- Linux에서는 Bramble이 이미 실행 중일 때 Bramble을 열면 창이 다시 표시됩니다.
- '비밀번호 유출 여부 확인'을 켜면 Bramble이 이제 직접 여는 로그인뿐 아니라 모든 로그인을 백그라운드에서 확인하며, 각 로그인에 마지막 확인 시각이 표시됩니다.
- 목록의 ⋮ 메뉴에서 항목을 복제하거나 파일을 첨부할 수 있습니다.
- 이제 복사 항목은 항상 30초 후가 아니라 설정 → 일반 → 클립보드 자동 지우기에서 설정한 시간 후에 지워집니다.
- 2주마다 보관함 목록의 카드에서 한 번 후원을 요청합니다. 설정 → 정보 → 지원에서 '2주마다 다시 알림'을 끄면 더 이상 표시되지 않습니다.
