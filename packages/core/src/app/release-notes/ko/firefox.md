이제 유출 확인이 모든 로그인을 대상으로 하며, 각 항목의 메뉴에서 항목을 복제하거나 파일을 첨부할 수 있습니다.

- '비밀번호 유출 여부 확인'을 켜면 Bramble이 이제 직접 여는 로그인뿐 아니라 모든 로그인을 백그라운드에서 확인하며, 각 로그인에 마지막 확인 시각이 표시됩니다.
- 목록의 ⋮ 메뉴에서 항목을 복제하거나 파일을 첨부할 수 있습니다.
- 열 수 없는 보관함은 이제 비밀번호 없이 보관함 목록에서 삭제할 수 있습니다. '보관함 삭제'를 선택하세요.
- 변경한 로그인과 일치할 수 있는 저장된 로그인이 여러 개인 경우, 업데이트 카드가 이제 하나를 대신 선택하지 않고 어떤 로그인을 업데이트할지 물어봅니다.
- 이제 '이 사이트에서는 사용 안 함'은 도메인의 모든 사이트가 아니라 wiki.example.com과 같은 해당 사이트에만 적용됩니다.
- 2주마다 보관함 목록의 카드에서 한 번 후원을 요청합니다. 설정 → 정보 → 지원에서 '2주마다 다시 알림'을 끄면 더 이상 표시되지 않습니다.
