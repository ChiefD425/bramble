Firefox 및 1Password 7에서 비밀번호를 가져오고, 두 기기가 한 항목을 편집할 때 두 변경 사항을 모두 유지합니다.

- 두 기기가 한 항목의 서로 다른 부분을 변경하는 경우, 예를 들어 한 기기에서는 비밀번호를, 다른 기기에서는 메모를 변경한 경우 두 변경 사항이 모두 유지됩니다.
- Firefox와 1Password 7에서 비밀번호를 가져옵니다.
- 설정 → 백업 → 백업 가져오기에서 열려 있는 보관함에 Bramble 백업을 추가합니다. 이미 있는 항목은 두 번 추가되지 않습니다.
- KeePass 내보내기에 이제 패스키가 포함되므로 KeePassXC에서 패스키로 로그인할 수 있습니다.
